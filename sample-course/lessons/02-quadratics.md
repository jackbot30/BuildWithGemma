# Lesson 2 — Quadratic Functions

A **quadratic function** has the form `y = ax^2 + bx + c` with `a != 0`. Its graph is a
parabola.

## Two useful forms

- **Standard form:** `y = ax^2 + bx + c`
- **Vertex form:** `y = a(x - h)^2 + k`, where `(h, k)` is the vertex.

The vertex of a standard-form quadratic is at:

`h = -b / (2a)`, and `k = f(h)`.

## The quadratic formula

The roots (where `y = 0`) of `ax^2 + bx + c = 0` are:

`x = (-b ± sqrt(b^2 - 4ac)) / (2a)`

The quantity `b^2 - 4ac` is the **discriminant**:

- `> 0` → two real roots
- `= 0` → one repeated real root
- `< 0` → no real roots (two complex roots)

**Worked example A.** Solve `x^2 - 5x + 6 = 0`.

```
a = 1, b = -5, c = 6
discriminant = 25 - 24 = 1
x = (5 ± 1) / 2  →  x = 3 or x = 2
```

**Answer: x = 2 or x = 3.**

**Worked example B.** Find the vertex of `y = x^2 - 6x + 5`.

```
h = -(-6) / (2·1) = 3
k = 3^2 - 6·3 + 5 = 9 - 18 + 5 = -4
```

**Answer: vertex = (3, -4).**

**Worked example C.** Solve `2x^2 + 4x - 6 = 0`.

```
a = 2, b = 4, c = -6
discriminant = 16 + 48 = 64
x = (-4 ± 8) / 4  →  x = 1 or x = -3
```

**Answer: x = 1 or x = -3.**
