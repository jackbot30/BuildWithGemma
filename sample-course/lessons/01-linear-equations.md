# Lesson 1 — Linear Equations

A **linear equation** in one variable can be written `ax + b = 0`. A **linear function**
is `y = mx + b`, where `m` is the slope and `b` is the y-intercept.

## Slope-intercept form

`y = mx + b`

- `m` (slope) = rise over run = how much `y` changes when `x` increases by 1.
- `b` (y-intercept) = the value of `y` when `x = 0`.

The slope through two points `(x1, y1)` and `(x2, y2)` is:

`m = (y2 - y1) / (x2 - x1)`

## Solving a linear equation

Isolate the variable by undoing operations in reverse order.

**Worked example A.** Solve `3x + 7 = 22`.

```
3x + 7 = 22
3x = 15        (subtract 7)
x = 5          (divide by 3)
```

**Answer: x = 5.**

**Worked example B.** Solve `2(x - 4) = 10`.

```
2(x - 4) = 10
x - 4 = 5      (divide by 2)
x = 9          (add 4)
```

**Answer: x = 9.**

**Worked example C.** A line passes through `(1, 2)` and `(3, 8)`. Find its slope.

```
m = (8 - 2) / (3 - 1) = 6 / 2 = 3
```

**Answer: m = 3.**

## Graphing a line

Plot the y-intercept `(0, b)`, then use the slope to step to the next point
(`run` right, `rise` up), and draw the line through them. For `y = 3x - 1`: start at
`(0, -1)`, go up 3 / right 1 to `(1, 2)`.
